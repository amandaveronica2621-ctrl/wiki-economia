# Bens Públicos

## O que é

Bens públicos são bens que possuem duas características fundamentais: **não-rivalidade** (o consumo por uma pessoa não reduz a disponibilidade para outras) e **não-exclusão** (não é possível impedir alguém de usufruir do bem, mesmo que não tenha pago por ele).

Essas propriedades criam o **problema do carona** (free rider): como ninguém pode ser excluído, as pessoas têm incentivo para usufruir sem contribuir para o financiamento. Por isso, o mercado privado tende a suboferecer bens públicos, justificando a provisão pelo governo.

## Como funciona

Como bens públicos não geram receita suficiente via mercado (ninguém pagaria voluntariamente se pode usar de graça), o governo os financia por meio de impostos e os oferece à população. A decisão sobre quanto produzir envolve comparar o benefício marginal social com o custo marginal.

É importante distinguir bens públicos puros de **bens comuns** — que são rivais mas não excludentes (como peixes no oceano). Bens comuns sofrem da **tragédia dos comuns**: uso excessivo leva ao esgotamento do recurso, já que cada indivíduo tem incentivo para consumir o máximo possível.

## Exemplo prático

A iluminação pública é um bem público clássico: quando uma rua é iluminada, todos os pedestres se beneficiam, sem que o uso de um reduza a luz disponível para outros. A defesa nacional é outro exemplo — protege todos os cidadãos igualmente.
